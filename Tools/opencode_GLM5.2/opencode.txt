Run via the glm CLI Tool (Cloud-Connected Agent)
If you want to use GLM-5.2 as a fully agentic coding and terminal assistant 
(similar to Claude Code) using an API key from Z.ai or OpenRouter, you can 
use the official developer CLI wrappers.

Step 1: Install the CLI helper
Install the global GLM package via npm:
npm install -g @z_ai/coding-helper

Step 2: Configure your API KeyYou can pass your OpenRouter or Z.ai base URL 
endpoints and keys directly into your environment or settings:
export ZAI_API_KEY="your_api_key_here"
or 
$env:ZAI_API_KEY="bcf1b6c03d524c58868da0cd0cb28a2d.vgyAuZLd35EDun3B"  


Step 3: Launch the CLI AgentTo spin up the terminal assistant with GLM-5.2 preset as your active model, simply run:
glm --model glm-5.2
