Download the model
    ollama run qwen2.5-coder:7b
    ollama run qwen2.5-coder:14b
After download, to run the model and chat
    1. Via terminal
        ollama run qwen2.5-coder:7b
        ollama run qwen2.5-coder:14b
    2. Via continue extension
        set config.yaml appropriately. Example config.yaml is
        name: Main Config
        version: 1.0.0
        schema: v1
        models:
        - name: Qwen 2.5 Coder 7B
            provider: ollama
            model: qwen2.5-coder:7b
            roles:
            - chat
            - edit
            - apply
            - autocomplete
        - name: GLM 4
            provider: ollama
            model: glm4:latest
            roles:
            - chat
        - name: Nomic Embed
            provider: ollama
            model: nomic-embed-text:latest
            roles:
            - embed
        - name: qwen2.5-coder
            provider: ollama
            model: qwen2.5-coder
            capabilities:
            - tool_use
        - name: Qwen 2.5 Coder 14B
            provider: ollama

Kill  ollama completely
taskkill /F /T /IM ollama*
Get-Process ollama -ErrorAction SilentlyContinue | Stop-Process -Force

Start ollama service
    1. ollama serve
    or
    2. Enable your Integrated GPU: to try offloading work to your Intel graphics to speed up generation, stop the server (Ctrl + C) and restart it with this flag:
        $env:OLLAMA_IGPU_ENABLE=1
        ollama serve

To Verify ollama running
curl http://127.0.0.1:11434 or curl http://localhost:11434
or ollama list, ollama run qwen2.5-coder:7b



copy ollama from default to folder another folder completely
robocopy "C:\Users\admin\.ollama\models" "D:\Ollama\models" /E /COPYALL /MT:16 /R:2 /W:5
(robocopy command: significantly faster and more reliable than xcopy)

Delete the folder
Remove-Item -Recurse -Force "C:\Users\admin\.ollama\models"

update Windows Environment Variables so it uses the new folder
setx OLLAMA_MODELS "D:\Ollama\models"
[System.Environment]::SetEnvironmentVariable("OLLAMA_MODELS", "D:\Ollama\models", "User")
$env:OLLAMA_MODELS = [System.Environment]::GetEnvironmentVariable("OLLAMA_MODELS", "User")
$env:OLLAMA_MODELS  --> D:\Ollama\models

stop ollama, close all terminals, and reopen terminals and run ollama(ollama serve in one 
    terminal and ollama run/ollama launch in the another terminal)
