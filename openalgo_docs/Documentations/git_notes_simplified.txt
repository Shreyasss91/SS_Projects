Your New Daily 2-PC Workflow [Rebasing (git pull --rebase instead of just git pull) is Best for Solo Developers]
your seamless loop between PC 1 and PC 2 looks like this:
On PC 1: Code, commit, and git push.
Move to PC 2: Before doing anything else, run git pull --rebase (it will cleanly catch up your files).
On PC 2: Code, commit, and git push.
Move back to PC 1: Run git pull --rebase to sync back up.


To check if there are updates on the remote main branch before you pull (without altering or merging anything into your local working files)
git fetch origin   (for any new commits on remote origin)
git status          (if there are updates --> "Your branch is behind 'origin/main' by X commits.")
git diff main..origin/main (To see the actual code changes (the diff))




git log #shows you the history of all the commits you have made in your repository. It acts as the chronological diary of your project.
git log > output.txt #To export the complete history and entire message of every single commit into a text file
git log -p > output.txt #text file to contain the commit messages plus the actual lines of code that were added or removed in each commit
git log -p -4 --> To see the git log -p output for exactly the last 4 commits
git log -p -4 --format="" -> Hide Metadata & Messages (Code Only)
git diff HEAD~4 HEAD -> Combined Changes (Single Diff)(To get a single aggregated view of all modifications made over the last 4 commits)


git diff HEAD~4 HEAD -- '*.js' '*.py' --> Target specific files only: If you want to skip logs and only see changes in a specific language folder (like JavaScript or Python).
git log -p -4 -- ':(exclude)logs/' --> Exclude a specific folder: Skip all files within a dedicated logs/ directory
git log -p -4 -- ':(exclude)*.log' ':(exclude)*.tmp' --> Exclude multiple file types: Add another exclusion pattern if you also want to skip other generated files (like .tmp or .bak).
git diff HEAD~4 HEAD -- ':(exclude)logs/' --> Exclude an entire folder: Ignore all files inside a logs directory.
git diff HEAD~4 HEAD -- ':(exclude)*.log' ':(exclude)*.txt' --> Exclude multiple patterns: Ignore both .log files and .txt files.

To go back n coomits in time
1. Safely Look Around (Don't Change Anything)
	(If you just want to view your project exactly how it looked n commits ago 
	without losing or breaking your current work)
	git checkout HEAD~n (view your project exactly how it looked n commits ago)
	git checkout main   (get back to normal)
2. Keep Your Work but Undo the Commits
	git reset --soft HEAD~n

3. Permanently Erase the Last n Commits
	git reset --hard HEAD~n
