How to run:
cp .env.example .env          # fill in TELEGRAM_BOT_TOKEN and OPENALGO_API_KEY
pip install -r requirements.txt
python main.py

Key design decisions for future-friendliness:
Adding a new underlying (e.g. BANKEX) requires touching exactly two 
places — SUPPORTED_UNDERLYINGS in websocket_manager.py and 
UNDERLYING_CONFIG in option_chain_service.py. 

Every handler, alert engine, and service picks up the new symbol automatically.
The WebSocket connects once at startup and subscribes to all index quotes 
permanently, so /atm and /oc responses come from the in-memory cache with 
near-zero latency. Option chain premiums use optionchain() which returns all 
LTPs in a single HTTP call rather than one call per strike.


Python searches sys.path in order. The built-in package named database (or the telegram package from python-telegram-bot) 
shadows your local folder of the same name. Prefixing with bot_ makes the names unique and unambiguous. 
The telegram conflict is especially common because python-telegram-bot installs a top-level telegram package that your 
local telegram/ folder collides with.
